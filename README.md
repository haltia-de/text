# b8k-text

«Блокнот» для планшета Lenovo YOGA Tablet 10 (B8000-H) с оболочкой
[lenovo-b8000h-linux](https://github.com/trudenboy/lenovo-b8000h-linux).

Блокнот крупным шрифтом: новая заметка или недавние файлы, файл из «Файлов», «Сохранить» (новая заметка ложится в ~/Документы), вопрос перед уходом с несохранённым. Только текст в UTF-8, до 2 МБ.

Нужен только Python 3 с PyGObject (GTK 3); на другом компьютере работает так
же, без вибрации и вопросов в стиле оболочки. Установка: `sh install.sh [ROOT]`.
