# text

«Блокнот» среды [Haltia](https://github.com/haltia-de).

Блокнот: новая заметка или недавние файлы, файл из «Файлов», «Сохранить» (новая заметка ложится в ~/Документы), вопрос перед уходом с несохранённым. Только текст в UTF-8, до 2 МБ.

Нужен только Python 3 с PyGObject (GTK 3); на другом компьютере работает так
же, без вибрации и вопросов в стиле оболочки. Установка: `sh install.sh [ROOT]`.

Пакет `haltia-text`, команда `haltia-text`. До ADR 0004 — `b8k-text`: старое
имя команды и скрытый `.desktop` старого id остаются до 3.0, а недавние файлы
переезжают из `~/.local/share/b8k-text` при первом запуске.
